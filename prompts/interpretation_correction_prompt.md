# 영어 문장 해석 교정 프롬프트

다음 형식으로 교정해줘.

---

1. 📘 **원문 문장**
   {{original_sentence}}

2. 📝 **My Interpretation**
   {{my_interpretation}}

3. ✅ **Corrected Interpretation**
   자연스럽고 정확한 해석/독해로 수정해주세요.

4. 🔍 **Analysis**

- 구조적 오류: 있다면 설명
- 어휘 선택 오류: 있다면 설명
- 문법적 오류: 있다면 설명
- 의미 왜곡 여부: 있다면 설명
- 전반적 피드백: 한 문장으로 요약

아래 형식을 그대로 사용해주세요. 전문적이되 너무 과하지 않게, 학습에 도움될 정도로만 분석해주세요.

## 입력값

- 원문 문장: {{original_sentence}}
- 학습자의 해석: {{my_interpretation}}

## 출력 규칙

- 학습자의 해석이 정확한 부분은 먼저 인정해주세요.
- 단순히 정답만 제시하지 말고, 의미가 달라진 부분과 빠진 부분을 구분해주세요.
- 해석에 문제가 없으면 억지로 오류를 만들지 말고, 잘 이해한 점과 추가로 익힐 표현만 설명해주세요.
- 출력은 위의 1~4번 형식을 유지해주세요.
