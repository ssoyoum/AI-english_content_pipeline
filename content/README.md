# 수동 콘텐츠 입력 형식

LLM API 없이 진행할 때는 사용자가 만든 콘텐츠를 문장별로 정리합니다.

```text
[1] Original sentence
[1] 나의 기준 해석 또는 올바른 해석

[2] Original sentence
[2] 나의 기준 해석 또는 올바른 해석
```

가능하면 문장마다 다음 정보도 함께 제공합니다.

- 핵심 의미
- 중요 영어 표현
- 자주 할 수 있는 오해
- 추가 학습 포인트

이 정보가 있으면 API 없이도 사용자의 입력을 규칙 기반으로 비교하고, 놓친 부분을 빨간색으로 표시할 수 있습니다. 원문과 해석만 제공해도 프로젝트에서 문장별 규칙을 만들어 사용할 수 있습니다.
